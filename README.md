# Mecânica Diesel Nova Nascimento

Projeto extensionista de Desenvolvimento Web Comunitário com IA e Git.

## Sobre o projeto

O projeto consiste no desenvolvimento de um site institucional responsivo para a **Mecânica Diesel Nova Nascimento**, localizada em **Nova Iguaçu - RJ**. A solução busca ampliar a presença digital do negócio e facilitar o contato dos clientes com a empresa.

## Objetivo

Criar uma presença digital simples, moderna e acessível para apresentar a empresa, seus serviços e disponibilizar um canal direto de atendimento via WhatsApp.

## ODS relacionada

**ODS 8 – Trabalho Decente e Crescimento Econômico.**

O projeto contribui com a digitalização e modernização de um pequeno negócio local, utilizando tecnologia para melhorar sua visibilidade e comunicação com clientes.

## Requisitos funcionais

- RF01: Exibir informações da empresa.
- RF02: Apresentar os principais serviços da mecânica.
- RF03: Disponibilizar telefone e localização da empresa.
- RF04: Permitir contato direto por meio do WhatsApp.
- RF05: Possuir navegação entre as seções Início, Sobre, Serviços e Contato.
- RF06: Adaptar a navegação para dispositivos móveis.

## Requisitos não funcionais

- RNF01: Interface responsiva para celular e computador.
- RNF02: Boa legibilidade e organização visual.
- RNF03: Carregamento rápido utilizando HTML, CSS e JavaScript sem dependências pesadas.
- RNF04: Compatibilidade com navegadores modernos.
- RNF05: Código organizado e versionado no GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- Inteligência Artificial como apoio ao desenvolvimento

## Estrutura

- `index.html` – estrutura e conteúdo do site
- `style.css` – identidade visual e responsividade
- `script.js` – interação do menu em dispositivos móveis

## Desenvolvimento

O projeto foi construído de forma incremental, com commits separados para demonstrar a evolução do código, conforme as boas práticas de versionamento solicitadas na atividade acadêmica.
